# نخشا — فرانت‌اند (React + Vite)

این پوشه شامل اپ فرانت‌اند نخشا است. از Vite و TailwindCSS استفاده می‌کند و برای توسعه محلی با HMR تنظیم شده است.

نکات سریع:

- زبان UI: فارسی (RTL)
- برای توسعه محلی: `cd frontend` سپس `npm install` و `npm run dev`

برای برنامه‌ریزی تولیدی، توصیه می‌شود TypeScript و قواعد lint پیشرفته اضافه شود.
